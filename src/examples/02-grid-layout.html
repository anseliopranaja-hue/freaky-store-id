📋 Ringkasan CSS Grid

Properti Fungsi Contoh Tailwind
display: grid Aktifkan Grid grid
grid-template-columns Definisi kolom grid-cols-3, grid-cols-[1fr_2fr]
gap Jarak antar items gap-4, gap-6
grid-column Span kolom col-span-2
grid-row Span baris row-span-2
justify-self Alignment horizontal justify-self-center
align-self Alignment vertical align-self-start

🤔 Flexbox vs Grid: Kapan Pakai yang Mana?

  • Flexbox: Layout 1 dimensi (baris ATAU kolom) — navigasi, kartu produk, centering
  • Grid: Layout 2 dimensi (baris DAN kolom) — katalog produk, dashboard, layout kompleks
  • Rule of thumb: Jika layout bisa digambar dengan 1 garis → Flexbox. Jika butuh grid → Grid.

🏆 Tantangan Akhir: Dashboard E-Commerce

Buat layout dashboard E-Commerce dengan CSS Grid:

  1. Header full-width (4 kolom)
  2. Sidebar kiri (1 kolom, 3 baris)
  3. Main content (3 kolom, 2 baris) — berisi statistik
  4. Footer full-width (4 kolom)

💡 Tips: Gunakan grid-cols-4 sebagai base, lalu col-span-* untuk item yang melebar.
