📝 Demo 1: Tipografi Responsif

Ukuran font berubah otomatis sesuai ukuran layar. Coba resize browser atau test di DevTools.

Judul yang Berubah Ukuran

Paragraf ini juga berubah ukuran sesuai breakpoint. Mobile: text-sm (14px), Tablet: text-base (16px), Desktop: text-lg (18px).

💡 Class yang digunakan:
text-2xl md:text-3xl lg:text-4xl — judul responsif
text-sm md:text-base lg:text-lg — paragraf responsif

🎯 Tantangan untuk Anda:

  1. Tambahkan breakpoint xl:text-5xl pada judul
  2. Buat paragraf dengan text-xs sm:text-sm md:text-base lg:text-lg
  3. Coba font-normal md:font-bold lg:font-extrabold

👁️ Demo 3: Hide/Show Element

Beberapa elemen hanya tampil di device tertentu. Resize browser untuk melihat perubahannya.

🖥️ Desktop: 📱 Mobile: Teks ini berbeda di mobile vs desktop
💻 Hanya tampil di layar besar (lg+): Element ini disembunyikan di mobile & tablet
📱 Hanya tampil di mobile & tablet: Element ini disembunyikan di desktop
📱 Mobile Only: Tampil hanya di mobile
📱 Tablet Only: Tampil hanya di tablet
💻 Desktop Only: Tampil hanya di desktop

💡 Pola Hide/Show:
hidden md:block → hidden di mobile, block di tablet+
hidden lg:block → hidden di mobile/tablet, block di desktop
lg:hidden → block di mobile/tablet, hidden di desktop
block md:hidden → block di mobile, hidden di tablet+

🎯 Tantangan untuk Anda:

  1. Buat button yang hanya tampil di mobile: block md:hidden
  2. Buat banner promo yang hanya tampil di desktop: hidden lg:block
  3. Buat menu yang berbeda di mobile vs desktop

📋 Ringkasan Breakpoints Tailwind

Prefix Min-width Device Contoh Penggunaan
(default) 0px 📱 Mobile Styling dasar untuk semua device
sm: 640px 📱 Large Mobile Phablet, mobile landscape
md: 768px 📱 Tablet iPad, tablet portrait
lg: 1024px 💻 Laptop Laptop kecil, tablet landscape
xl: 1280px 💻 Desktop Laptop besar, desktop
2xl: 1536px 🖥️ Large Desktop Monitor besar, 4K

💡 Tips Mobile-First Design:

  • Tulis styling mobile tanpa prefix dulu
  • Tambahkan prefix untuk layar lebih besar (md:, lg:)
  • Test di DevTools dengan berbagai device
  • Prioritaskan konten penting di mobile
  • Gunakan hidden/block untuk hide/show element

🏆 Tantangan Akhir: Halaman Produk Responsif

Buat halaman detail produk yang responsif:

  1. Mobile: Gambar di atas, detail di bawah (stack vertical)
  2. Desktop: Gambar di kiri (1/2), detail di kanan (1/2)
  3. Tipografi: Font kecil di mobile, besar di desktop
  4. Button: Full-width di mobile, auto-width di desktop

💡 Template:
flex flex-col md:flex-row gap-8
md:w-1/2 untuk gambar dan detail
text-2xl md:text-4xl untuk judul
